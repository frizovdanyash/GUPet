# Документация GUPet

Эта документация описывает настройки GUPet и формат пользовательских скинов. Целевая страница: <https://doc.guteam.net/pet>.

## Первое включение

1. Установите приложение и нажмите **«Позвать питомца»**.
2. В системном окне Android включите разрешение **«Показывать поверх других приложений»**.
3. Вернитесь в GUPet. Питомец появится поверх открытых приложений.
4. Чтобы скрыть питомца, выключите его в настройках или нажмите **«Остановить»** в постоянном уведомлении.

Доступ к уведомлениям необязателен. Он нужен для музыкальных реакций и, при отдельном включении, локальной обработки уведомлений. GUPet не записывает звук.

## Управление питомцем

- **Касание** — питомец отвечает.
- **Двойное касание** — прыжок.
- **Удержание** — поглаживание.
- **Перетаскивание** — перенос питомца.
- **Бросок после перетаскивания** — короткий полёт.
- **«Покакать сейчас»** — ручной вызов кучки в любой момент, даже если самостоятельные события отключены.
- Касание кучки удаляет её. Кнопка **«Убрать кучки»** очищает все кучки.

Раздел поведения позволяет включать прогулки, реплики, гравитацию, реакцию на встряхивание, вибрацию, танец под музыку и реакции на уведомления. Эти функции можно включать независимо.

## Пользовательские скины `.gupet`

Файл `.gupet` — обычный ZIP-архив, расширение которого изменено на `.gupet`. Архив не содержит исполняемого кода: только манифест и изображения. Все файлы должны лежать в корне архива, без вложенных папок.

### Обязательные требования

- В архиве должен быть `manifest.json` и обязательный кадр `idle.png`.
- Каждый PNG должен быть размером **18 × 13 пикселей**. Подходит RGBA с прозрачным фоном.
- Общий распакованный размер архива — не более **2 МБ**; каждый PNG — не более **512 КБ**; манифест — не более **16 КБ**.
- Допускается до десяти записей архива, включая папки, если они есть. Для совместимости лучше помещать только файлы в корень.
- `id` состоит из строчных латинских букв, цифр, дефиса или подчёркивания и начинается с буквы либо цифры. Длина — до 40 знаков.
- Кадр `idle` обязателен. Для остальных состояний приложение использует `idle`, если соответствующий кадр не добавлен.
- Если импортировать архив с уже установленным `id`, прежний скин с этим идентификатором будет заменён.

### Поддерживаемые кадры

| Ключ в манифесте | Имя PNG | Когда показывается |
| --- | --- | --- |
| `idle` | `idle.png` | Обычное состояние; обязателен |
| `blink` | `blink.png` | Моргание |
| `happy` | `happy.png` | Радость и обычная реакция на касание |
| `sleep` | `sleep.png` | Сон и зевок |
| `dance` | `dance.png` | Танец под активную медиасессию |
| `surprised` | `surprised.png` | Удивление |
| `dizzy` | `dizzy.png` | Головокружение |
| `angry` | `angry.png` | Недовольство |
| `love` | `love.png` | Реакция с сердечками |

Анимация движения, прыжки, наклон, частицы и покачивание применяются к пользовательскому изображению так же, как к встроенным питомцам. Скин заменяет вид и окрас питомца; выбор пользовательского вида не изменяет остальные настройки поведения.

### Пример `manifest.json`

```json
{
  "format": "GUPet",
  "formatVersion": 1,
  "id": "mint-cat",
  "name": "Мятный кот",
  "author": "Автор скина",
  "width": 18,
  "height": 13,
  "frames": {
    "idle": "idle.png",
    "blink": "blink.png",
    "happy": "happy.png",
    "sleep": "sleep.png",
    "dance": "dance.png"
  }
}
```

### Создание и импорт

1. Нарисуйте прозрачный PNG размером 18 × 13 пикселей. Начните с файла `idle.png`.
2. При желании нарисуйте дополнительные кадры. Имена PNG должны совпадать с ключами в `frames`.
3. Создайте `manifest.json` и укажите уникальные `id`, имя, автора, размер и список кадров.
4. Поместите манифест и PNG в корень ZIP-архива. Например, в архиве должны быть `manifest.json`, `idle.png` и необязательные PNG-кадры, без внешней папки.
5. Создайте ZIP и переименуйте его, например, в `mint-cat.gupet`.
6. В GUPet откройте **«Пользовательские скины» → «Импорт .gupet»**, выберите архив и нажмите на его карточку, чтобы выбрать скин.
7. Удалить установленный скин можно кнопкой корзины на его карточке.

Для пробы доступны шаблон [`GUPet-template.gupet`](examples/GUPet-template.gupet) и авторский скин **«Искра»**: [скачать `.gupet`](examples/Iskra.gupet), [посмотреть PNG-превью](examples/Iskra-preview.png). Архив «Искра» можно импортировать сразу или распаковать, чтобы изучить несколько кадров.

## Хранение данных

Настройки и импортированные изображения хранятся локально в закрытом хранилище приложения. Импортированный архив не отправляется в сеть. Удаление скина в приложении удаляет его локальные файлы.
