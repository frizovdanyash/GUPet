GUPet

Инструкция по настройке питомца и созданию пользовательских скинов.

Первое включение

  1. Установите приложение и нажмите «Позвать питомца».
  2. В системном окне Android разрешите показывать поверх других приложений.
  3. Вернитесь в GUPet. Питомец появится поверх открытых приложений.
  4. Чтобы скрыть питомца, выключите его в настройках или остановите через постоянное уведомление.

Доступ к уведомлениям необязателен. Он нужен для музыкальных реакций и выбранных пользователем реакций на уведомления. Звук не записывается.

Управление питомцем

  • Касание — питомец отвечает.
  • Двойное касание — прыжок.
  • Удержание — поглаживание.
  • Перетаскивание — перемещение; бросок запускает короткий полёт.
  • Кнопка «Покакать сейчас» вызывает кучку в любой момент, даже если самостоятельные события выключены.
  • Касание кучки удаляет её, а кнопка «Убрать кучки» очищает все кучки.

В настройках можно выбирать GUPet, кошку или собаку, менять окрас и размер, а также включать прогулки, реплики, гравитацию, вибрацию, музыкальные анимации и реакции на уведомления.

Пользовательские скины .gupet

Файл .gupet — ZIP-архив с расширением .gupet. В нём находятся только manifest.json и PNG-кадры; исполняемый код не поддерживается.

  • Все файлы должны лежать в корне архива, без вложенных папок.
  • Обязателен файл idle.png; каждый PNG — ровно 18 × 13 пикселей.
  • Подходит RGBA PNG с прозрачным фоном.
  • Распакованный архив — до 2 МБ, один PNG — до 512 КБ, манифест — до 16 КБ.
  • Можно добавить до девяти кадров: idle, blink, happy, sleep, dance, surprised, dizzy, angry и love.

Манифест

{
  "format": "GUPet",
  "formatVersion": 1,
  "id": "mint-cat",
  "name": "Мятный кот",
  "author": "Автор скина",
  "width": 18,
  "height": 13,
  "frames": {
    "idle": "idle.png",
    "blink": "blink.png",
    "happy": "happy.png",
    "sleep": "sleep.png",
    "dance": "dance.png"
  }
}

Идентификатор id должен состоять из строчных латинских букв, цифр, дефиса или подчёркивания; первый знак — буква или цифра, длина — до 40 знаков. Название — до 40 символов. Необязательные кадры заменяются кадром idle, если не добавлены.

Как собрать и установить

  1. Нарисуйте idle.png и, при желании, дополнительные кадры.
  2. Сохраните PNG и манифест в корень ZIP-архива.
  3. Создайте архив и переименуйте его, например, в mint-cat.gupet.
  4. В приложении откройте «Пользовательские скины» → «Импорт .gupet», выберите файл и нажмите на его карточку.
  5. Удаление выполняется кнопкой корзины рядом с установленным скином.

Если повторно импортировать скин с тем же id, прежняя версия будет заменена.

Хранение данных

Настройки и импортированные изображения хранятся в закрытом хранилище приложения. Архив скина не отправляется в сеть. Удаление скина в приложении удаляет его локальные файлы.
