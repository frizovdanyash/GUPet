# GUPet — пиксельный питомец для Android

GUPet — небольшой пиксельный питомец, который появляется поверх приложений. Он гуляет, прыгает, отдыхает, реагирует на касания и может танцевать под музыку.

## Возможности

- Три встроенных вида: GUPet, кошка и собака; шесть цветовых палитр и регулируемый размер.
- Импорт пользовательских скинов в формате `.gupet`, выбор и удаление скинов прямо в приложении.
- Тап, двойной тап, поглаживание, перетаскивание и бросок запускают разные реакции и анимации.
- Питомец самостоятельно гуляет, машет, засыпает и выглядывает из-за края экрана.
- По желанию включаются гравитация, реакция на наклон, вибрация, реплики, реакции на уведомления и танец при воспроизведении музыки.
- Кучку можно вызвать вручную в любой момент, убрать касанием или очистить все кучки кнопкой.
- Настройки оформлены в стиле Material 3. Данные и пользовательские скины хранятся локально на устройстве.

## Установка

1. Установите APK и откройте GUPet.
2. Нажмите **«Позвать питомца»** и разрешите отображение поверх других приложений в системном окне Android.
3. Вернитесь в приложение. Управляйте питомцем из настроек или через постоянное уведомление.
4. Разрешение на доступ к уведомлениям необязательно. Оно используется для определения активных медиасессий и выбранных пользователем реакций на уведомления; звук не записывается.

На некоторых устройствах для продолжительной работы может понадобиться исключить приложение из оптимизации батареи.

## Пользовательские скины

Скин — ZIP-архив с расширением `.gupet`. В архиве находятся `manifest.json` и PNG-кадры размером **18 × 13 пикселей**. Обязателен кадр `idle.png`; дополнительные кадры можно добавить для моргания, сна, радости, танца и эмоций.

Полная инструкция, шаблон и готовый скин «Искра» доступны в [документации на русском языке](docs/pet/README.md). Адрес целевой страницы документации: <https://doc.guteam.net/pet>.

## Сборка

Требуются JDK 17, Android SDK Platform 35 и Android Build Tools 35.0.0.

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Debug-сборка предназначена для ручной установки и тестирования. Для публикации с постоянной подписью создайте собственный release-ключ.

## Права и приватность

- `SYSTEM_ALERT_WINDOW` используется только для отображения плавающего питомца.
- Foreground-сервис поддерживает питомца на экране; его можно остановить из уведомления.
- Датчик движения и вибрация используются только при включённых настройках.
- Доступ к уведомлениям необязателен. Состояние медиасессий используется для музыкальных анимаций; звук не записывается. Текст уведомления, если включены реакции, проверяется локально и не передаётся приложением в сеть.
- Пользовательские скины импортируются из выбранного пользователем архива и хранятся в закрытой папке приложения.
