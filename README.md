# PixPet — Пиксельный питомец

Нативный Android-питомец, который живёт поверх приложений. Порт и приложение: **@frizovdanya**. Идея и поведение основаны на Telegram-плагине **Clawd 1.5 от @itskotovski** — см. [NOTICE.md](NOTICE.md).

## Что умеет

- Плавающий пиксельный питомец: Clawd, кошка или собака; 6 окрасов и настраиваемый размер.
- Тап — реакция, двойной тап — прыжок, удержание — погладить, перетаскивание и бросок — полёт.
- Самостоятельно гуляет, машет, засыпает, выглядывает из-за края; опционально использует гравитацию, наклон, акселерометр и лёгкую вибрацию.
- Реплики, частицы-сердечки/искры/ноты и танец под аудио Telegram.
- Кучку можно вызвать кнопкой **«Покакать сейчас»** или дождаться случайного события. Её можно убрать касанием, а все кучки — кнопкой **«Убрать кучки»**. Максимум одновременно — три.
- Позиция, вид питомца и настройки сохраняются на устройстве.
- Настройки построены на Jetpack Compose Material 3; поддерживается системная динамическая палитра.

## Что намеренно не переносилось

- Питомец **не съедает и не скрывает** кнопки, иконки или другие элементы интерфейса. Логика поиска объектов, снимков экрана, «выплёвывания» и восстановления отсутствует.
- Отдельное Android-приложение не имеет доступа к внутренним Telegram-хукам: оно не определяет открытый чат, не читает список сообщений и не реагирует на отправку. Для распознавания новых Telegram-уведомлений можно по желанию выдать доступ к уведомлениям. Реакция определяется локально по коротким ключевым словам; текст не сохраняется и не передаётся.
- Без специальных привилегий Android-питомец не видит геометрию пузырей чата и не может стоять на них; при включённой гравитации он приземляется у края экрана.

PixPet не использует Accessibility Service, захват экрана, интернет-разрешение или сетевую передачу текста уведомлений.

## Установка

1. Установите APK из GitHub Releases или соберите `app-debug.apk` по инструкции ниже.
2. Запустите PixPet и нажмите **«Позвать питомца»**.
3. В системном окне Android разрешите **отображение поверх других приложений**, затем вернитесь в PixPet.
4. Питомец останется на экране, пока не выключить его в настройках или из постоянного уведомления PixPet. Уведомление нужно для корректной работы foreground-сервиса Android.
5. Доступ к уведомлениям для Telegram необязателен. Включайте его только если хотите реакции на уведомления и Telegram-аудио; разрешение выдаётся в системных настройках Android.

На некоторых прошивках для продолжительной работы поверх приложений дополнительно потребуется исключить PixPet из оптимизации батареи.

## Сборка из исходников

Требуются JDK 17, Android SDK Platform 35 и Android Build Tools 35.0.0. В корне проекта:

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Сборка `debug` подписывается временным Android debug-ключом: подходит для ручной установки и тестирования, но для публикации в Google Play и обновлений с постоянной подписью создайте собственный release-ключ.

## Права и приватность

- `SYSTEM_ALERT_WINDOW` — только чтобы рисовать небольшой плавающий виджет питомца.
- Foreground service — удерживает виджет активным; его можно остановить из уведомления.
- Акселерометр и вибрация используются только если соответствующие настройки включены.
- Notification Listener — полностью необязателен. При его включении PixPet проверяет локально заголовок/текст уведомления только чтобы выбрать настроение; содержимое не логируется, не хранится и не отправляется.
