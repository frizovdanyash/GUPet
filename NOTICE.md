# Attribution and scope

PixPet is an independent Android pixel-pet app inspired by the on-screen pet concept and interaction design in the Clawd Telegram plugin (version 1.5), originally credited to **@itskotovski**. The Android application and its Kotlin implementation are credited to **@frizovdanya**.

The supplied plugin did not contain a license notice. PixPet does not bundle or republish the original Python plugin source; it independently implements compatible pet behavior for Android. The object-eating / hiding / restoring UI-elements behavior was intentionally omitted. Please contact the original plugin author for permission before redistributing that plugin or its source.
