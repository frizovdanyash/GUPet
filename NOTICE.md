# Attribution and scope

PixPet is an independent Android reimplementation of the on-screen pixel-pet idea and interaction design in the Clawd Telegram plugin (version 1.5) supplied for this port, originally credited to **@itskotovski**. The Android application and its Kotlin implementation are credited to **@frizovdanya**.

The supplied plugin did not contain a license notice. PixPet does not bundle or republish the original Python plugin source; it reimplements the compatible pet behavior for Android. The object-eating / hiding / restoring UI-elements behavior was intentionally omitted. Please contact the original plugin author for permission before redistributing that plugin or its source.
